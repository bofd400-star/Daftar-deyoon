# دفتر ديون المحل

تطبيق ويب قابل للتثبيت على آيفون وأندرويد، بمزامنة سحابية عبر Supabase وحساب واحد على عدة أجهزة.

## النشر
1. أنشئ مشروعاً على https://supabase.com.
2. افتح SQL Editor وشغّل محتوى `schema.sql` مرة واحدة. في مشروع جديد وفارغ فقط؛ إذا كانت الجداول موجودة، راجع السياسات قبل التنفيذ.
3. من Authentication > Providers فعّل Email. اضبط تأكيد البريد حسب رغبتك. استخدم كلمة مرور قوية وفريدة.
4. من Project Settings > API Keys انسخ Project URL و**publishable** أو **anon** key فقط. **لا تستخدم secret أو service_role**.
5. ارفع ملفات هذا المجلد إلى استضافة HTTPS ثابتة (مثل Netlify Drop أو Cloudflare Pages). بعد النشر افتح رابط التطبيق وأدخل إعدادات Supabase.
6. أنشئ الحساب مرة واحدة، ثم سجّل الدخول بنفس الحساب على كل جهاز. في iPhone: Safari > مشاركة > إضافة إلى الشاشة الرئيسية. في Android: Chrome > تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
7. للمزامنة المباشرة، فعّل Realtime للجداول `customers` و`entries` من لوحة Supabase. حتى بدون Realtime، زر تحديث يجلب أحدث البيانات.

## تنبيهات
- لا تحفظ بيانات زبائن حقيقية قبل التأكد من إعداد RLS، النسخ الاحتياطية، والأمان.
- لا يوجد نشر سحابي تلقائي في هذه الحزمة؛ تحتاج إلى استضافة وإعداد Supabase.
- عند انقطاع الإنترنت، يتاح فتح الواجهة إن كانت مخزنة مسبقاً، لكن تسجيل العمليات يحتاج اتصالاً.
- حساب واحد مشترك يعني أن كل جهاز يستطيع رؤية وتعديل بيانات الحساب؛ تجنب مشاركته مع غير الموثوقين.
- يمكن تصدير CSV للنسخ الاحتياطي يدوياً.
- تسديدان متزامنان من جهازين قد يتجاوزان الرصيد لأن التحقق من الرصيد يتم في الواجهة؛ يوصى بإضافة تحقق ذري على الخادم قبل الاستخدام التجاري الكثيف.
